# 사이트 분리 3단계: 관리자 사이트

기존 기준 사이트의 주소와 저장소를 유지하면서 시작 화면을 학교 관리자 전용으로 전환합니다. 이후 교사·학생 사이트를 별도로 추가해 같은 학교 저장소에 연결합니다. 세 개의 새로운 저장소를 만드는 방식이 아닙니다.

## 화면별 기능

| 화면 | 기능 |
| --- | --- |
| 학교 운영 현황 | 재학생·졸업생·원본/분석 준비·계정 승인 대기 현황, 필요한 작업으로 이동 |
| 학생 관리 | 학년도·학급·재학 상태·자료 준비 필터, 학번/이름/이메일 검색, 50명 단위 목록 |
| 학생 등록 | 기존 엑셀 양식 다운로드·업로드·붙여넣기·오류 행 수정, 1명 등록 |
| 학생 상태 | 졸업 연도 확인 후 졸업 처리, 재학 복원, 기존 학생 ID·원본·분석 이력 유지 |
| 학급·담임 배정 | 2·3학년 학급 추가, 학년도 검색, 승인된 교사 선택 후 저장 |
| 계정·접근 관리 | 학교 계정 승인 확인, 역할별 계정 검색, 기존 사이트 로그인 연결·해제·처리 이력 |
| 공용 평가 자료 | 기존 모집요강·평가 기준 파일 등록, 자료 판본·적용 범위·승인 상태 관리 |
| 저장소·백업 | 기존 Google 연결·자료 이전, 원본 포함 전체 백업, 자료 관계 점검 |
| 학생 자료 열람 | 기존 학생부 원본·Work 결과·성적·활동·연구지문·역량·위키·지도 기능 |

운영 현황은 예시 학생을 제외하며 자료 준비 지표는 실제 재학생만 계산합니다. 이 지표는 파일과 활성 분석의 등록 여부이며, 학생 역량이나 합격 가능성 점수가 아닙니다. 학생 검색에서는 예시·재학·졸업·보관 상태를 명시적으로 선택할 수 있습니다.

## 사용 순서

1. 학급·담임 배정에서 학급을 만듭니다. 교사 계정 승인 전에는 관리자가 임시 담당할 수 있습니다.
2. 학생 관리 → 엑셀 일괄 등록에서 양식을 내려받고 명단을 작성합니다. 업로드·붙여넣기 후 오류 행과 대상 학급을 확인해 등록합니다.
3. 계정·접근 관리에서 본인을 확인한 뒤 학생 또는 담임 계정을 승인합니다. 학생은 등록 이메일이 일치하고 기존 계정이 다른 학생에 연결되지 않은 경우에만 연결합니다.
4. 승인된 담임을 학급에 배정합니다. 저장 후 담당 교사의 자료 접근 범위가 변경됩니다.
5. 학생 목록의 이름 또는 ‘원본·분석 열람’을 누르면 해당 학생이 선택된 상세 화면으로 이동합니다. ‘관리자 운영 화면’으로 돌아올 수 있습니다.
6. 공용 평가 자료에 모집요강 등을 등록합니다. AI 분석은 Work에서 수행하고 JSON 결과를 기존 절차로 검증·반영합니다.
7. 저장소·백업에서 연결 점검과 원본 포함 백업을 실행합니다. Google 이전 전에는 전체 백업을 생성·검증합니다.

## 접근과 저장

- 기준 사이트의 서버 환경 변수 `TRACE_PORTAL_MODE=admin`, `TRACE_HOME_SITE_ID=기준 사이트 ID`를 설정합니다. 기존 `TRACE_GOOGLE_LOCATIONS` 등 다른 설정은 보존합니다.
- `/api/admin`은 매 요청마다 승인된 관리자 여부와 저장된 역할·사이트 연결 상태를 다시 검사합니다. 학생·교사·정지·승인 대기 계정에는 관리 자료를 제공하지 않습니다.
- `/workspace` 역시 관리자만 열 수 있습니다. 관리자와 학생·교사 역할을 화면에서 임의 전환하는 기능은 없습니다.
- 계정·학생·학급·자료 ID를 새로 발급하거나 기존 표를 복사하지 않습니다. 데이터베이스 구조를 바꾸는 마이그레이션은 없습니다.
- 수정은 기존 공통 데이터 처리 함수를 사용합니다. Google 전환 후에는 같은 Google 저장소에 기록합니다.
- 저장은 성공했으나 목록 갱신에 실패하면 ‘저장 완료, 목록 재확인’으로 안내하여 중복 등록을 유도하지 않습니다. 최신 자료를 불러오기 전에는 추가 변경을 중단합니다.
- D1 학생 계정 승인에서도 다른 계정에 이미 연결된 학생을 덮어쓰지 못하도록 검사합니다.

## 검증과 운영상 남은 사항

관리자 전용 API의 비로그인·교사·학생·승인 대기 접근 거부, 저장된 역할 검사, 해제된 로그인 연결, 기존 학생 계정 연결 보호, 학급 담당 변경, 일괄 등록, 졸업·복원과 ID 유지, 예시/졸업생을 제외한 운영 지표를 자동 시험합니다. 기존 교과·원본·Google·백업·지도 기능도 회귀 검증합니다.

구현 당시 운영 Google 연결 설정은 없었습니다. 원본과 학교 자료는 기존 저장소에 남아 있으며 Google 소유자 실행 승인·웹 앱 배포·자료 이전은 완료하지 않았습니다. 실제 계정의 Google 권한 승인은 이 작업의 테스트로 대체되지 않습니다.

현재 Sites 접근 범위는 기존 소유자 전용을 유지합니다. 학생·교사 사이트 개설과 사용자별 사이트 공유는 다음 단계이며, 고급 관리자 통계·대규모 자동 운영·자동 복원은 이번 최소 관리자 사이트 범위에 포함하지 않습니다.
