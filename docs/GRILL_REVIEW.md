# 그릴미 검토와 개선

2026-09-18. [grill-me의 검증 절차](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md)를 참고해, 이미 정해진 학생·교사·관리자 권한과 기록 보존 원칙을 실제 실패 조건에 대조했다. 아래 내용은 가상 자료로 재현한 결함이며 실제 학생 자료 유출을 확인했다는 뜻은 아니다.

## 확인된 문제와 수정

| 검증 질문 | 재현 결과 | 반영한 수정 |
| --- | --- | --- |
| 한 계정이 두 학생에게 연결되면 모든 화면이 차단하는가? | 학생 전용 API만 차단했다. 공통 조회·지도 저장·다른 학생의 원본 다운로드는 허용됐다. | D1과 Google 공통 권한 함수에서 전체 학생 연결 수를 검사한다. 보관·졸업 학생도 포함한다. 중복이면 학생의 자료 접근을 중단하며 관리자에게 확인을 요청한다. |
| 동시에 등록해도 학생 계정이 한 명에게만 연결되는가? | D1 등록 요청 두 개가 모두 사전 검사를 통과해 같은 계정을 연결할 수 있었다. | DB INSERT·UPDATE 트리거로 중복을 막고 명단 등록·계정 승인을 한 트랜잭션으로 저장한다. 실패한 요청의 미완성 명단을 남기지 않는다. |
| 파일 목록이 정상이면 원본도 정상인가? | 같은 크기의 손상 파일도 재사용·이전 완료 검사를 통과했다. | Drive 파일 존재·보관 폴더·크기·SHA-256 내용을 대조한다. 삭제·손상 시 이전을 완료하지 않는다. 원본 다운로드도 내용 검증을 거친다. |
| 저장소 전환과 취소가 겹쳐도 최신 기록을 보존하는가? | 최종 저장 요청 중 취소가 기존 저장소를 열 수 있어 추가 기록이 이전본에서 빠질 수 있었다. | 작업 ID와 복사·검증·저장 단계를 저장하고 조건부 갱신으로 진행한다. 최종 검증 시작 후 취소를 차단한다. |
| 원격 저장 후 응답이 끊기면 안전하게 재시도하는가? | 기존에는 저장 여부가 불확실한 상태에서도 취소할 수 있었다. | 원격 저장 전에 저장 확인 단계를 기록한다. 응답이 끊겨도 기존 자료를 동결하고 같은 자료의 완료 확인만 허용한다. |
| 오래된 화면이나 멈춘 작업이 새 작업을 덮을 수 있는가? | 이전 세션을 식별할 값과 최종 검증 처리자 구분이 없었다. | 다른 작업 ID는 거절한다. 검증 처리자에 3분 임대와 토큰을 사용하고, 처리자 변경 후 이전 요청은 저장할 수 없게 한다. 연결 확인 응답도 이전 시작 후 URL을 바꾸지 못한다. |

## 관리자 화면 사용

- 원본 복사 중에는 `이어서 복사·검증` 또는 `이전 중단 · 기존 저장소 사용`을 선택할 수 있다.
- 최종 검증·저장 확인 중에는 `완료 확인 다시 실행`과 `상태 새로고침`을 제공한다. 이미 실행 중이면 완료를 기다리고, 중단된 작업은 3분 뒤 다시 확인한다.
- 원격 저장 여부가 불확실하면 기존 저장소를 수정할 수 없다. 같은 작업의 완료 확인으로 복구한다.
- 원본 손상·삭제 등 원격 저장 전 검증 실패는 복사 단계로 돌아간다. 원본을 복구하고 검증하거나 이전을 중단해 기존 저장소를 계속 사용할 수 있다.
- 구형 Google 연결 코드는 원본 내용 검증 기능을 제공하지 않으므로 최신 개인 설치 코드를 적용하고 `setupTrace` 실행 및 같은 웹 앱의 배포 버전 갱신을 완료해야 한다.

## 데이터 보존과 검증 범위

새 마이그레이션 `0008_storage_migration_session.sql`을 추가했다. 기존 학생 행을 삭제·병합하지 않는다. 이미 중복 연결된 자료가 있다면 관리자 자료 점검과 계정 확인 후 수정해야 한다. 이후 생성되는 중복 연결은 DB에서 거절한다. 이전 버전에서 진행 중이던 저장소 전환은 기록을 동결한 채 완료 확인 단계로 승계한다.

회귀 시험에는 공통 API 접근 차단, 동시 등록, 기존 중복 자료의 마이그레이션 보존, Google 권한 검사, 같은 크기 손상, 삭제 파일, 전환 중 취소, 응답 유실 후 재시도, 오래된 작업 ID, 검증 임대 만료, 연결 확인과 전환 시작의 경합을 포함했다. 실제 경로 함수와 Google Apps Script 템플릿을 가상 D1·Drive·Sheets 환경에서 실행했다.

Google 소유자 권한 승인과 실제 데이터 이전, 학생·교사 사이트의 공통 저장소 연결은 코드 개선과 별개의 운영 단계다. 실제 계정 로그인 시험과 실자료 전환을 완료했다고 표시하지 않는다. AI 분석은 계속 Work에서 수행한다.

검증 결과: 전체 자동 시험 107개와 TypeScript 검사가 통과했다. 내부 미리보기의 가상 전환 상태에서 복사·완료 확인 버튼 구분, 최종 확인 단계의 취소 숨김, 상태 새로고침, 복사 중단 후 기존 저장소 복귀 및 새 백업 요구를 확인했다. 미리보기용 설정은 확인 후 제거했다.
