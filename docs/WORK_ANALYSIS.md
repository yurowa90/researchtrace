# 현재 학년 분석과 공용 평가 자료

2학년은 1학년 기록, 3학년은 1·2학년 기록을 기본 자료로 사용합니다. 현재 학년의 실제 기록이 있으면 함께 분석합니다. 파일 업로드에서 포함된 학년을 모두 선택하고 학년도를 확인합니다. 현재 학년 일부 학기만 있어도 등록할 수 있습니다.

관리자는 **공용 평가 자료실**에서 대학·전형·모집 학년도·자료 종류를 등록합니다. 교사는 자료를 선택한 뒤 **분석 자료 선택 저장**을 누릅니다. 선택은 교사별로 유지되며 이후 학생의 Work 요청문에 자동으로 반영됩니다.

처음 한 번 **선택 자료 한 번에 받기**로 실제 파일과 출처 목록을 받아 Work에 제공합니다. 같은 Work 공간에서 이미 접근 가능한 자료는 반복 첨부하지 않습니다. 새 대화에서 접근할 수 없는 자료나 개정된 파일만 다시 제공합니다. 사이트에 등록했다는 사실만으로 Work가 원문을 읽은 것으로 간주하지 않습니다.

학생별 **Work 결과 → 분석 요청문 복사**를 사용합니다. 분석 결과의 `sourceYears`는 실제 기록의 학년도를 최대 3개 포함할 수 있습니다. 없는 학기·성적·역량을 채우지 않습니다. 등록된 현재 학년 기록이 결과에서 빠지면 검증 오류로 안내합니다.

공용 자료는 `LIB-숫자` 출처 ID와 제목·대학·전형·학년도·종류를 대조합니다. 새 판본은 새 파일로 등록하며 이전 자료를 보관 처리해 기존 분석 출처를 유지합니다. 분석 보조점수는 공식 평가점수나 합격 확률이 아닙니다.

## 1.2 결과와 한 번에 받기

‘Work 자료 묶음 받기’는 선택한 학생의 원본, 분석 요청문, JSON 예시, 선택한 공용 평가 자료와 출처 목록, Work 포함을 선택한 지도 기록, 이전 활성 분석 결과를 ZIP으로 제공합니다. 최대 100MB이며 학생 간 자료를 섞지 않습니다. 사이트가 Work에 직접 전송하지 않으므로 받은 파일을 현재 Work에 제공합니다.

공용 자료는 관리자가 판본·자료 단계·확인일을 기록하고 승인합니다. 1.2 결과에는 자료의 해시와 판본 번호도 포함합니다. 자료가 개정·보관 처리되거나 지원 학년도가 바뀌면 이전 분석에 재점검 안내가 나타납니다. 연구보고서나 교원 연수 자료의 제안을 확정 전형 조건으로 입력하지 않습니다.

새 결과는 `schemaVersion: "1.2"`를 사용합니다. 각 근거에 원본 ID와 페이지, 직접 기록·자기보고·해석·계획·미확인 상태를 구분합니다. 실제 기록이 있는 학년만 포함하고 알 수 없는 학점은 `null`로 둡니다. 점수 산출 기준이 없으면 역량 점수를 만들지 않습니다. 기존 1.0/1.1 분석은 계속 열람할 수 있습니다.

질문은 이전 질문에서 달라진 점과 이유, 사용한 방법·자료, 학생의 설명·수정 과정을 보존합니다. 자기보고를 교사가 직접 관찰한 사실로 바꾸거나 계획한 실험을 수행한 실험으로 바꾸지 않습니다. 실제 기록에 없는 학기·진로 일관성·성장을 보충하지 않습니다.
