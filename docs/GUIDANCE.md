# 지도·근거·계획 기능

## 학생

‘다음 행동·피드백’에서 질문 하나, 다음 할 일, 읽기·설명 기록, 분석 정정 요청을 작성합니다. 질문의 출발, 연결 교과, 범위를 바꾼 이유, 실제 근거를 필요한 만큼 추가합니다. 교과 성취, 학습 루틴, 공동체 기여는 선택 항목입니다.

실행 결과를 제출하고 교사에게 받은 보완 사항을 반영합니다. 확인 완료된 기록은 학생이 덮어쓸 수 없습니다. ‘진학·과목 계획’에는 지원 희망, 방향·진로·학기·당장 할 일 목표, 희망 과목을 저장합니다. 희망 과목은 이수학점으로 계산하지 않습니다.

## 담임

담당 학급의 제출·정정 요청을 확인하고 근거, 피드백, 확인 상태를 기록합니다. 학생 자기보고, 관찰 사실, 교사의 해석을 구분합니다. 비공개 메모는 담당 교사와 관리자만 조회하며, Work 자료 포함 여부도 별도로 선택합니다.

연구지문과 위키에서 연결 근거와 원본 페이지를 확인하고, 분석 버전의 추가·삭제·근거 변경을 비교합니다. 위키는 제목·목록·표·내부 링크와 인쇄를 지원합니다. 서버가 원본 PDF의 특정 페이지를 자동 추출하지는 않습니다.

## 관리자

학교 개설 과목과 공용 평가 자료의 판본·발표일·확인일·단계·승인 상태를 관리합니다. 확정 자료에 직접 확인한 과목·학점 조건과 페이지를 입력하면 학생의 지원 연도·대학·전형·교육과정·모집단위가 맞는 경우에만 점검합니다. 안내서·연구자료·사례집을 확정 모집요강으로 자동 해석하지 않습니다.

진급·반 이동 시 기존 학생 ID를 유지하여 원본·분석·지도 이력을 연결합니다. Google 저장소 연결 후에는 학교 설정에서 수동 데이터 백업을 생성할 수 있습니다. 백업은 표 데이터와 원본 위치 목록이며 원본 파일의 별도 복제본은 아닙니다.

## 데이터와 검증

- 새 `guidance_entries` 표에 변경 이력을 추가합니다. 기존 표를 재작성하는 마이그레이션은 없습니다.
- Work 1.2 결과의 기록 ID·페이지·상태, 자료 판본·해시를 검증합니다. 1.0/1.1 결과도 계속 읽을 수 있습니다.
- 학점 미확인은 `null`로 유지하고, 중복·충돌 내역은 실제 이수 합계에서 구분합니다. 5등급·9등급·성취평가를 동일 척도로 합산하지 않습니다.
- 서버의 본인·담당 학급·전체 권한, 비공개 메모, 동시 수정 충돌, 원본 중복 업로드, 반 이동 후 이력을 검증합니다.
- Apps Script 검증은 실제 운영 코드를 Google API 응답 모형에서 실행한 것입니다. 소유자 Google 승인과 실제 연결 확인은 설치 화면에서 진행해야 합니다.

## 현재 범위 밖

사이트 자동 AI 분석·OCR, 자동 합격 가능성 예측, 자동 기재 적법성 판정, 자동 백업 일정·복원, 학교 코호트별 장기 비교, 모바일 푸시 알림은 구현하지 않았습니다. 학생부 검토와 기준 승인에는 담당 교사의 확인이 필요합니다. 원본이 이미지로만 되어 있으면 Work에서 판독 가능 여부를 별도로 확인합니다.
